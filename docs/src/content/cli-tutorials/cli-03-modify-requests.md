# 修改请求 {#modify-requests}

在上一步中，我们不加改动地放行了被拦截的请求。
拦截的全部威力，要在我们把被拦截的请求转发到目的地之前先修改它时才真正体现出来。
你可以继续使用上一步的窗口和已经配置好的拦截规则。
