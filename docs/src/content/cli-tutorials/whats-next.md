# 下一步 {#whats-next}

恭喜！你已经成功完成了 mitmproxy 教程。🎉

在本教程中，我们用 mitmproxy 检查了由 curl 发起的请求。
你大概也想检查来自浏览器或其他工具的网络流量。
要做到这一点，你需要
[把 mitmproxy 配置为客户端的代理]({{< relref "/overview/getting-started#configure-your-browser-or-device" >}})。

本教程只覆盖了 mitmproxy 最基础的功能。我们强烈建议你也浏览一下接下来的章节，
那里更详细地讲解了大部分核心概念。
